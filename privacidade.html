Política de Privacidade

Última atualização: 07/10/2026

O Controle Contábil Lógica é um sistema de uso administrativo destinado à organização e controle de atividades contábeis.

Uso das informações

As informações acessadas pelo sistema são utilizadas exclusivamente para permitir o funcionamento das funcionalidades autorizadas pelos usuários.

Dados do Google

Quando autorizado pelo usuário, o sistema pode utilizar serviços do Google necessários ao funcionamento de determinadas funcionalidades. O acesso ocorre somente mediante autorização do usuário.

Os dados obtidos não são vendidos nem utilizados para publicidade.

Compartilhamento

As informações dos usuários não são comercializadas com terceiros.

Segurança

São adotadas medidas destinadas a proteger as informações utilizadas pelo sistema contra acesso não autorizado.

Revogação de acesso

O usuário pode revogar as permissões concedidas ao aplicativo através das configurações de segurança da sua Conta Google.
